# Анкета-диагностика «Капитал нового уровня»

Одностраничный сайт-анкета ([index.html](index.html)), которую эксперт заполняет вместе с клиентом на созвоне.

## Структура анкеты (6 блоков)

1. **Знакомство** — имя, дата, точка А/Б
2. **Финансовая ситуация** — доход/расход, подушка, кредиты
3. **Цели** — калькулятор сложного процента (достижима ли цель при текущей стратегии)
4. **Опыт инвестирования** — чек-листы инструментов
5. **Главный барьер**
6. **Резюме** — выбор рекомендуемого курса-маршрута из 5 вариантов

## Дополнительно

- Живой пересчёт калькулятора и hero-блока по ходу заполнения
- Экспорт в PDF (`window.print()`)
- Демо-модалка «отправка в Битрикс24» (пока имитация, не реальная интеграция)
- **Сохранение анкет** — кнопка «💾 Сохранить анкету» отправляет данные в Google Таблицу через Google Apps Script ([apps-script/Code.gs](apps-script/Code.gs), инструкция в [apps-script/README.md](apps-script/README.md)); URL веб-приложения уже вписан в код.

## Технически

Чистый HTML/CSS/JS, без сборки и зависимостей (кроме Google Fonts).
