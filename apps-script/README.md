# Сохранение анкет в Google Таблицу

Настройка занимает ~5 минут, всё делается в корпоративном Google-аккаунте.

## 1. Создайте таблицу
1. На корп. Google Диске создайте новую Google Таблицу, например «Анкеты диагностик».
2. Откройте её → **Расширения → Apps Script**.
3. Удалите содержимое `Code.gs`, вставьте туда код из файла [`Code.gs`](./Code.gs) этого репозитория.
4. Сохраните проект (значок дискеты), можно назвать его «Anketa Webhook».

## 2. Разверните как веб-приложение
1. В редакторе Apps Script: **Deploy → New deployment**.
2. Тип — **Web app**.
3. Настройки:
   - **Execute as:** Me (ваш аккаунт)
   - **Who has access:** Anyone (или «Anyone within [ваша организация]», если сайт открывается только сотрудниками/клиентами через корп. сеть — так безопаснее, но проверьте, что клиенты смогут отправлять форму)
4. Нажмите **Deploy**, разрешите доступ (запросит подтверждение прав на редактирование таблицы).
5. Скопируйте выданный **URL веб-приложения** (заканчивается на `/exec`).

## 3. Подключите к сайту
В файле `index.html` найдите строку:

```js
const SHEET_WEBAPP_URL = 'ВСТАВЬТЕ_СЮДА_URL_РАЗВЁРНУТОГО_APPS_SCRIPT';
```

Замените на скопированный URL, например:

```js
const SHEET_WEBAPP_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

Сохраните файл и опубликуйте сайт.

## 4. Проверка
1. Откройте сайт, заполните несколько полей.
2. Нажмите **«💾 Сохранить анкету»** в шапке.
3. В таблице появится новая строка на листе «Анкеты» (лист создастся автоматически при первой отправке).

## Важно про обновления скрипта
Если позже меняете код в `Code.gs`, нужно сделать **новый деплой** (Deploy → Manage deployments → Edit → New version), иначе изменения не применятся к уже выданному URL.

Для полей раздела 6 нужна новая версия скрипта из репозитория:
`summaryA`, `summaryB`, `recommendedFormat`. После обновления при первом
сохранении он добавит недостающие заголовки справа от существующих колонок.
Старые ответы и порядок старых колонок сохраняются. До обновления развёртывания
старый обработчик эти три поля не записывает, хотя в анкете и PDF они уже есть.

## Безопасность
- URL веб-приложения даёт право дописывать строки в таблицу — не публикуйте его нигде, кроме самого сайта (тела скрипта).
- Если нужно закрыть отправку только для внутренних сотрудников — используйте вариант доступа «Anyone within organization» при деплое (Google Workspace).
