# Шрифты анкеты

Локальные копии исходных **Golos Text** (400, 500, 600, 700) и
**Cormorant Garamond** (500, 600, 700), полученные 14.09.2026 из Google Fonts.
Оба семейства распространяются по SIL Open Font License 1.1; тексты лицензий
сохранены рядом. Шрифты используются и на экране, и в PDF.

Источник CSS со статическими TTF (без современного browser User-Agent):
https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&family=Cormorant+Garamond:wght@500;600;700

Исходники и лицензии:
- https://github.com/google/fonts/tree/main/ofl/golostext
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

При обновлении сохраняйте полные наборы кириллицы и знак рубля. Экспорт
дожидается всех семи начертаний до вызова печати, поэтому нельзя удалять
отдельные файлы без обновления `fonts.css` и `pdf-export.js`.
