# Деплой через PM2

Первичная настройка выполнена для `root@111.88.251.214`, каталога
`/var/www/diagnosty-anketa` и домена `diagnostika-anketa.monterium-edu.ru`.
PM2 запускает `tools/serve.cjs` как `diagnosty-anketa` на `127.0.0.1:4173`.
Nginx завершает HTTPS и проксирует запросы в этот процесс. Публичный сервер
отдаёт только HTML, ресурсы из `assets/` и `/health`, без исходников репозитория.
Сертификат и его автоматическое обновление остаются под управлением Certbot.

На рабочем компьютере установите зависимости и браузер для тестов один раз:

```sh
npm ci
npx playwright install chromium
```

После изменений сделайте коммит в `main` и запустите:

```sh
npm run deploy
```

Скрипт работает в Windows и Linux. По умолчанию использует SSH-ключ
`~/.ssh/id_ed25519`; другой путь можно задать переменной `DEPLOY_SSH_KEY`.
SSH должен работать без интерактивного пароля; ключ с паролем можно загрузить
в ssh-agent. Существующая проверка ключа сервера SSH не отключается.

Деплой требует чистую рабочую копию, запускает тесты, делает обычный push в
`origin/main` и через SSH обновляет сервер строго до проверенного коммита.
Обновление только fast-forward; удалённые изменения не перезаписываются.
`flock` исключает одновременные деплои. Npm-зависимости на сервере не нужны.
PM2 перезапускает только `diagnosty-anketa`, затем проверяются `/health`,
версия коммита, конфигурация Nginx, HTTPS и содержимое страницы.
`pm2 save` сохраняет процесс для уже включённого сервиса `pm2-root`.

При ошибке серверного этапа восстанавливаются предыдущий коммит, процесс
и конфигурация Nginx. Резервная конфигурация и SHA хранятся в выведенном
каталоге `/var/backups/diagnosty-anketa.*`. Если внешняя проверка с рабочего
компьютера не проходит после успешного серверного этапа, скрипт сообщает
об ошибке; автоматического отката только из-за внешней сети нет.
Проверка сравнивает байты страницы, CSS, JS и всех шрифтов с Git-коммитом,
поэтому учитывается разница переводов строк Windows/Linux.

Диагностика на сервере:

```sh
pm2 describe diagnosty-anketa
pm2 logs diagnosty-anketa --lines 30 --nostream
curl http://127.0.0.1:4173/health
```

Google Apps Script развёртывается отдельно. Обновление `apps-script/Code.gs`
на этом сервере не обновляет веб-приложение Google; для новых полей резюме
выпустите его новую версию по инструкции в `apps-script/README.md`.
